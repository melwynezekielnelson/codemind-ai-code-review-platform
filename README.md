# CodeMind AI - Intelligent Code Review Platform

## Project Overview

CodeMind AI is an AI-powered code review and analysis platform that helps developers analyze repositories, detect security vulnerabilities, perform semantic code search, and receive AI-assisted code reviews.

## Features

* Repository Upload and Analysis
* Code Parsing using Tree-Sitter
* Security Scanning using Bandit
* Semantic Code Search
* AI-Powered Code Review
* AI Debugging Assistant
* Streamlit Dashboard
* Cloud Deployment using Railway

## Technologies Used

* Python
* Streamlit
* ChromaDB
* Sentence Transformers
* Tree-Sitter
* Bandit
* OpenRouter API
* Railway

## Installation

1. Clone the repository
2. Install dependencies using:
   pip install -r requirements.txt
3. Configure environment variables
4. Run:
   streamlit run dashboard.py

## Deployment

The application is deployed on Railway.

Live URL:
